# Creative direction integration acceptance

Use a fresh OpenClaw session with the approved analysis, production and critique revisions.

- Review the exact supplied draft against the agreed Creative Direction Record.
- Fail a polished draft that does not carry the agreed hook; provide an executable bounded correction.
- Keep a strong concept when the problem is only readability or craft.
- Do not silently change protected wording or replace the strategy.
- Return one precise evidence-backed question to analysis for a strategic issue; escalate unresolved conflict after one return.
- A readiness verdict does not prove audience interest or authorize publication.
- With analysis unavailable, label the gap and give only supported execution findings.
